# BlogBucket

A full-stack blogging platform built with React, Node.js, Express.js, MySQL, and JWT Authentication.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Role-Based Access Control (Admin/User)
- Create, Edit & Delete Blog Posts
- Profile Management
- Featured Image Upload
- Responsive UI
- Protected Routes
- REST API
- MySQL Database

## 🛠️ Tech Stack

### Frontend

- React
- React Router
- Axios
- CSS Modules

### Backend

- Node.js
- Express.js
- MySQL
- JWT
- Multer
- Joi

## 📂 Project Structure

```
BlogBucket
│
├── frontend
├── backend
├── database
│   └── BlogBucket.sql
```

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Backend

```bash
cd backend
npm install
```

Create a `.env` file using `.env.example`.

Start backend:

```bash
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Database

Import:

```
database/BlogBucket.sql
```

into MySQL.
